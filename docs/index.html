01 / First boot

From JAR to first hatch

Use Paper, install the correct Java runtime, and let OmniPet copy its starter pack. Existing servers should complete the migration checklist before the first production start.

  1. 01
    Place the artifact

    Copy `OmniPet-<version>.jar` into `plugins/`.

  2. 02
    Start once

    Review the generated `plugins/OmniPet/` YAML files.

  3. 03
    Grant slots

    Assign `petstorage.slot.1` and additional slot permissions.

  4. 04
    Issue an egg

    Run `/pets item egg common <player>`.

Architecture boundary

Core rules. Optional adapters. Honest fallbacks.

The intended direction keeps Paper gameplay in the core while MythicLib, MMOItems, and future ModelEngine support live behind capability checks. Missing vendor plugins should disable only their feature, not OmniPet.
