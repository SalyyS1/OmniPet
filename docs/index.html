01 / Staging boot

From verified JAR to a controlled server check.

Use the Gradle release artifact on staging, preserve old data, and verify only the features that currently ship.

  1. 01
    Place the artifact

    Copy OmniPet-3.0.0-SNAPSHOT.jar into plugins/.

  2. 02
    Start on staging

    Confirm the Studio-enabled log line or capture the first fail-closed error.

  3. 03
    Open shipped flows

    Use /pet, /pet slot, and permitted Studio/admin branches.

  4. 04
    Verify recovery

    Run /pet admin transactions 20; paste the opaque next cursor when provided, and never replay an ambiguous economy call.

Architecture boundary

Persisted intent is not a live pet.

The current runtime stores definitions, owned pets, desired-active UUIDs, slot entitlements, and recovery evidence. Hatching, entities, movement, runtime buffs, skills, and item gameplay need later implementations and live certification.
