# Incubation / Economy / Release saga defect review (scout-sagas -> planner)

Read-only pass over incubation (held + placed + action items), player controllers, economy adapters, release outbox/mailbox, entitlement, and the core saga/lock code (2026-09-03). No gradle run, no files modified. Report persisted by planner from the scout's inline message (scout had no Write tool).

All paths under `omnipet-paper/src/main/java/io/github/salyvn/omnipet/paper/` unless prefixed `core/` (= `omnipet-core/src/main/java/io/github/salyvn/omnipet/core/`).

## Summary
- Placed-egg flow has a hard gap: an egg that becomes READY via instant-hatch item, while owner offline, or with a full vault never hatches; only exit is breaking it, which hands back the raw egg and discards all incubation time.
- Placement/break handlers run at NORMAL and persist before protection plugins can cancel; combined with no `isEggBlock`/owner check on break this is a duplication + griefing path.
- Slot purchase withdraws inside the player file lock while waiting up to 10s for the main thread; main-thread action-item redeem takes the same lock with no deadline -> tick freeze up to 10s per purchase.
- Release rewards have no join-time retry; MAILBOX_PENDING (full inventory at release) waits for an operator. Mailbox grows unbounded and `list` throws past 10k files.
- Core sagas (egg escrow, slot purchase, outbox) are sound; defects are in the Paper adapters/timing, not the state machines.

## Upgrade opportunities
- Join-time release outbox + mailbox recovery (bounded, sequential, async) reusing the cultivation recovery pattern.
- Ready-egg retry pass with in-flight guard; CLAIM action in placed-egg menu; message owner on grant failure with reason.
- `SharedRepositoryLockRegistry`: bounded `tryLock` with deadline + `IllegalStateException`/deferral instead of infinite spin; assert not main thread in `FilePlayerStateRepository.withLocked`.
- Provider calls outside repository locks; `future.cancel(false)` on timeout in `PaperProviderCallExecutor`.
- Placed-egg listener: MONITOR-priority persistence, `isEggBlock` + owner gate on break, creative handling, chunk-loaded guard in `refresh`, `ChunkLoadEvent` hologram respawn.
- Mailbox archival + truncation flag; per-player mailbox lookup (`findByPlayer`) so `list` and join recovery are O(player).
- Self-heal INVENTORY_CLAIMING via gateway PDC evidence; cap reward stack counts.
- Operator identity in release reconcile evidence (parity with slot reconcile).
- Move action-item redeem saga off main thread.
- Merge the two Paper inventory adapters.
