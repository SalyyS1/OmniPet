# Command / GUI / Config / Studio defect review (scout-ux)

Read-only scout of `omnipet-paper` player + operator surfaces. No files modified, no gradle run.
Base path `P` = `omnipet-paper/src/main/java/io/github/salyvn/omnipet/paper`.

## Summary

- No P1. GUI click safety is uniformly good (cancel-first, holder + viewer + bounds checks, drag cancel, per-click permission re-check on admin menus, `PetManagementInventoryGuard` identity check).
- One real logic defect: `MenuLayout` mis-handles an out-of-range configured slot (item redrawn at default slot, action left at unreachable slot = dead button on hub/hatch/admin-tx menus).
- Message catalog parity is clean (308 `MessageKey` paths == 308 `lang/vi.yml` leaves, no legacy section-sign codes), but 83 hardcoded English `sendMessage("...")` sites bypass it = mixed-language output with `gui.locale: vi`.
- Config: `config.yml` header promises reload "never fails silently"; only `runtime` changes warn. `render.nameplateStatus` dropped by legacy-migration `encode()`. Docs miss several admin subcommands.
- Latent MiniMessage injection through pet custom name into nameplate (visible to all nearby players); unreachable today because no rename UI ships, but the safety rationale in the `Messages.operator` javadoc is wrong.

## Upgrade opportunities

- `/pet version` (or `/petadmin version`): plugin version, git commit, Paper API, storage schema versions, provider status (MythicLib / ModelEngine / Vault / PlayerPoints). None exists today (`grep "version"` across the command package: 0 hits).
- bStats metrics: none (`grep -ri bstats`: 0 hits). Add `Metrics` with custom charts (locale, storage mode, provider presence).
- Update checker (Modrinth / Hangar / GitHub releases) with console notice + op join notice and an opt-out key.
- Reload warnings for every RESTART ONLY key (render, petsPerPage, promptTimeout, studio session timeout) so the `config.yml:8-10` promise is true.
- Migrate the 83 hardcoded strings into the catalog; add a contract test asserting no `sendMessage("` literal under `paper/**` (or an explicit allowlist).
- Derive `canUse`, `/pet help`, the docs table, and tab-complete from `OmniPetCommandTree`; extend the contract test to diff `docs/commands-and-permissions.md`.
- `MenuLayout` out-of-range test + fix; then port `PetManagementMenuRenderer` and `PlayerPetMenuRenderer` onto `MenuLayout` so every menu is restylable through `gui.menus`.
- Escape pet custom names in nameplates now (pre-rename hardening).
- `gui.studio.sessionTimeoutSeconds` config key; make prompt/session timeouts live-reloadable (rebuild `ChatInputService` on reload, or read from `GuiSettings` per prompt).
- `admin stats` offline-player support via `PlayerArgumentResolver`.
- Remove `FoundationCommand`, `COMMAND_FOUNDATION_READY`, and `omnipet.admin.explore` (or ship explore).
- One `MainThreadBridge` helper to replace the three copies of the CompletableFuture-to-main-thread pattern (`PetCultivationActionCoordinator.java:276-316`, `PetManagementControllerContext.java:94-119`, `PaperCultivationRecoveryController.java:134-136`).
